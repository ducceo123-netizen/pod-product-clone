# POD Product Clone

Standalone system for converting proven POD competitor demand into differentiated Give Mories products.

## Core flow

Competitor Truth -> Demand Mechanism -> Opportunity Map -> 3 Directions -> Asset Layer Blueprint -> Variant Matrix -> Give Mories Thumbnail Plan -> Ad-Angle Bridge -> User Review -> Optional Memory Package

## Isolation

This repository is intentionally independent from Creative DNA.

- no shared resolver
- no shared knowledge tables
- no shared proposals
- no hidden Creative DNA fallback

## Commands

```bash
npm install
npm run typecheck
npm run dev
```

# POD Product Clone — Skill Contract

## Trigger
Use when the user asks to analyze, clone, differentiate, reverse-engineer, rework, or build a POD product based on competitor product/print/ad evidence.

Preferred invocation:

POD Clone — Analyze

Product: <competitor URL>
Print file: <attachment>
Ads: <video / images / notes>
Goal: Create differentiated variant for Give Mories

## Required reasoning flow
1. Extract competitor source truth.
2. Identify demand mechanisms and purchase triggers.
3. Mark KEEP / CHANGE / EXPLORE.
4. Produce 3 materially different product directions.
5. Decompose selected direction into production asset layers.
6. Build scalable personalization/variant matrix.
7. Reapply thumbnails to Give Mories' PDP language.
8. Translate into distinct acquisition angles.
9. Wait for user review.
10. Only package memory after explicit instruction.

## Output sections
- Source Truth
- Opportunity Map
- Three Variant Directions
- Asset Layer Blueprint
- Variant Matrix
- Thumbnail / PDP Image System
- Ad-Angle Bridge

## Isolation
This system must never silently query or inherit Creative DNA. Any cross-system reference must be explicit in the user's request.
